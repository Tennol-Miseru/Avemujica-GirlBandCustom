**Minecraft 1.21.1 · Fabric · v1.1.125 · Java 21**

将 Ave Mujica 的五位成员带入 Minecraft。模组围绕一支可召集、可培养、可演奏、可巡演、可经营，也能参与战斗的少女乐队展开；它不只是角色展示或皮肤替换，而是一套包含音乐、模拟经营、社交与战斗的综合玩法。

> 本项目为粉丝制作的非官方 Minecraft 模组，与 BanG Dream!、Ave Mujica、相关版权方及原作开发团队无官方隶属或背书关系。

## 五位成员

| 角色 | 英文标识 | 乐队定位 |
|---|---|---|
| 丰川祥子 | Oblivionis | 键盘／合成器 |
| 三角初华 | Doloris | 主唱与独立电吉他声部 |
| 若叶睦 | Mortis | 电吉他 |
| 八幡海铃 | Timoris | 贝斯；拥有独立战斗形态 |
| 祐天寺若麦 | Amoris | 架子鼓 |

五位成员拥有独立的外观、语音、互动与日常行为。NPC 外观统一采用 Minecraft 原版 Alex / Slim `PlayerModel`，每位成员使用独立的 64×64 皮肤；不需要 GeckoLib。成员资料和成长数据按玩家保存；召集、队伍指令、个人互动与舞台行为共同构成乐队系统。
五位成员默认皮肤由soten_bori老师制作！
## 模组特色

### 音乐与 MIDI 演奏

- 内置曲目 **KillKiss（模组内置）**，也支持导入玩家自己的 MIDI 文件。
- 支持全队演奏、成员独奏、排练与正式演出；演奏动作会响应 MIDI 音符与乐器声部。
- 初华的人声与电吉他是独立声部、独立设置；人声不替代吉他演奏。
- 提供成员乐器音量设置、乐器音色／效果器配置，以及可选的自定义 OGG 乐器采样。
- 战斗音乐可使用当前选定的乐队 MIDI 曲目，并与舞台演奏状态分开管理。

### 舞台与现场演出

- 可搭建并升级巡演舞台，包含乐器、舞台装饰与主题灯光。
- 成员会根据演奏声部触发相应动作；支持单人试奏与全队演出。
- 舞台演出、排练和村庄巡演连接乐队成长与经营收益。

### 乐队经营与村庄巡演

- 通过排练培养成员、提升训练等级与乐队表现。
- 组织正式演出和村庄巡演，吸引观众、积累粉丝并领取演出奖励。
- 使用绿宝石经营舞台与周边；演出收入、巡演奖励和周边销售收益分别结算。
- 小章鱼控制台提供经营、成员管理、商店和周边寄售入口。

### 社交、相机与周边

- 提供相机拍摄、照片草稿、照片发布与社交动态功能。
- 可对照片点赞、置顶，并将照片制作成游戏内展示立牌。
- 包含乐队海报、唱片与五位成员的人偶等周边；支持购买、寄售、库存管理与销售收益领取。

### 角色与乐器自定义

- 可为五位成员替换 64×64 PNG 皮肤。
- 可替换已注册语音槽位中的 Ogg Vorbis 对话音频，并管理字幕。
- 可单独调整成员日常动作开关、召集开关及乐器外观颜色。
- 可为支持的乐器与初华人声导入自定义 OGG 音频。
- 自定义皮肤、对话语音和部分音色覆盖属于客户端本地资源；其他玩家需要自行安装相同素材才能看到或听到相同效果。

### 战斗

- 乐队成员可参与战斗，并具有各自的战斗行为与专属武器表现。
- 战斗 MIDI、武器音效与舞台演奏分别处理，不会把战斗状态误当作舞台演出。

## 安装

### 玩家安装

1. 安装 **Minecraft Java Edition 1.21.1**。
2. 安装适用于 Minecraft 1.21.1 的 **Fabric Loader**。
3. 安装对应版本的 **Fabric API**。
4. 从项目发布页下载与游戏版本、加载器匹配的 Ave Mujica `.jar`，放入游戏实例的 `mods` 文件夹。
5. 启动游戏。多人游戏中，客户端与服务器都需要安装模组，并保持相同版本。

**重要：** v1.1.120 更新了角色召集设置的网络数据结构；v1.1.125 延续该协议。联机时客户端与服务器必须同时使用同一版本，当前发布版本请两端都使用 v1.1.125。升级前请备份世界存档。

### 常用入口

- 手持蓝色小章鱼并右键，打开控制台；成员管理、角色自定义、乐器设置、经营和周边功能均可从界面进入。
- `/avemujica manage`：打开乐队经营界面。
- `/avemujica customize`：打开角色自定义界面。
- `/avemujica midi list`：查看可用 MIDI 曲目。
- `/avemujica midi play`：播放当前默认曲目。
- `/avemujica midi stop`：停止 MIDI 播放。
- `/avemujicaassets`：查看自定义素材目录；`/avemujicaassets reload`：重新导入并刷新自定义素材。

部分管理命令受权限等级限制。具体功能以游戏内界面和当前版本为准。

## 自定义素材

### MIDI

将 `.mid` 文件放入当前游戏实例的：

```text
config/avemujica/midi/
```

单机模式读取本机目录；连接远程服务器时，曲目还需要放入服务器对应目录。随后通过 MIDI 选曲界面或 `/avemujica midi list` 选择曲目。

### 皮肤与对话语音

自定义素材入口：

```text
config/avemujica/custom_assets/
```

皮肤使用 **64×64 PNG**；对话语音使用 **Ogg Vorbis**，并遵循已有角色与语音槽位规则。第一次导入后，需要在 Minecraft「选项 → 资源包」中启用 `AveMujica_Custom_Assets`。

## 从源码构建

### 环境要求

- JDK 21（需要 `javac`，不能只有 JRE）
- Gradle 8.14.6（或与 Fabric Loom 1.11.8 兼容的 Gradle 8.14.x）
- 首次构建需要网络下载 Minecraft、Fabric、Loom 等依赖

当前源码包未包含 Gradle Wrapper。请先安装 Gradle，或在 CI 环境中配置 Gradle 8.14.6。

在项目根目录运行：

```bash
gradle --no-daemon build
```

构建产物位于 `build/libs/`，选择普通模组 JAR，不要将 `-sources.jar` 当作游戏模组安装。
